# Implementação do Código de Huffman

Este repositório contém a implementação do algoritmo de Huffman para compressão de textos, desenvolvido como parte do Trabalho Individual da disciplina de Algoritmos e Estruturas de Dados.

##  Descrição do Projeto

O objetivo deste trabalho é consolidar conhecimentos sobre estruturas em árvore e codificação estatística. O programa desenvolvido realiza a leitura de textos, calcula a frequência das palavras, constrói uma árvore binária ponderada (Árvore de Huffman) e gera a versão comprimida dos dados.

O software foi projetado para:
1. Ler textos de entrada a partir de um arquivo `input.dat`.
2. Gerar a árvore de Huffman baseada na frequência das palavras.
3. Criar o mapeamento de códigos binários.
4. Exportar os resultados (árvore, códigos e texto comprimido) para `output.dat`.

##  Requisitos

* **Linguagem:** Python 3.x
* **Sistema Operacional:** Compatível com Linux (Ubuntu 24.04) e outros sistemas (Windows/macOS).
* **Dependências:** Apenas bibliotecas padrão do Python (`heapq`, `os`, `collections`). Não é necessária instalação de pacotes externos.
